# Welcome to My Reactjs Calculator
***

## Task
The goal of this project is to create a React-based calculator that performs basic arithmetic operations (addition, subtraction, multiplication, and division) while maintaining a clean UI and accepting both button and keyboard inputs.

## Description
This calculator:
✅ Allows multiple operations in a single input.
✅ Supports keyboard input for easy calculations.
✅ Displays formatted numbers using underscores (_) for better readability.
✅ Prevents division by zero and handles errors gracefully.
✅ Provides a clear (C) button to reset the calculator.
✅ Fully responsive professional UI design.

## Installation
Step 1: Clone the Repository

$> git clone https://github.com/your-username/reactjs-calculator.git
$> cd reactjs-calculator

Step 2: Install Dependencies
$> npm install

Step 3: Run the Application
$> npm start

This will start a local development server at http://localhost:3000/.

## Usage
1️⃣ Enter numbers and operators (+, -, *, /).
2️⃣ Press = or Enter to calculate the result.
3️⃣ Press C or Escape to clear the input.
4️⃣ Use Backspace to delete the last entered character.
